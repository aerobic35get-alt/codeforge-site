# Ошибка 403 Forbidden в Python: что делать?

Ты написал скрипт, запустил его, а вместо данных получил `403 Forbidden`. Это не значит, что твой код плохой. Это значит, что сайт понял, что ты — скрипт, и не хочет отдавать тебе данные.

## Почему это происходит?

Сервер видит твой запрос и смотрит на заголовок `User-Agent`. По умолчанию библиотека `requests` говорит: «Я библиотека Python». Сайт блокирует такие запросы, чтобы не нагружать себя ботами.

## Как исправить (по шагам)

### Вариант 1: Добавить правильный заголовок (самый простой)

Измени свой запрос вот так:

```python
import requests

url = "https://example.com"
headers = {
    "User-Agent": "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/91.0.4472.124 Safari/537.36"
}

response = requests.get(url, headers=headers)
print(response.status_code) # Теперь тут скорее всего будет 200
